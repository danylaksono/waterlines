Waterlines

Old-map ripples drawn on a 2D canvas over a live web map. Technique after Olivia Vane.

  • Nusantara — MapLibre The full thing: waterlines over the Indonesian archipelago, with style controls and a live frame-budget readout. Start here.
  • Studio The same map and the same panel, plus the two things you need for your own work: drop in a GeoJSON, and save the result as a PNG.
  • Still gallery The same renderer with no map, fitted to a box — presets side by side, and what happens without curve smoothing.
  • Nusantara — deck.gl The same overlay driven by a deck.gl viewport instead of a MapLibre transform.

The coastline files in data/ are committed, but they are generated: npm run data rebuilds them from Natural Earth.
